# Neprel Scoop bucket

Scoop manifests for public command-line tools maintained by Neprel.

```powershell
scoop bucket add neprel https://github.com/neprel/scoop-bucket
```

## Manifests

| Manifest | Install |
| --- | --- |
| `git-a2a` | `scoop install neprel/git-a2a` |

More manifests may be added without creating a separate bucket for each project.
